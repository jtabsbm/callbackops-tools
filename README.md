## Founding pilot

The lower-friction entry point is a fixed-scope **48-hour missed-lead signal audit for $250**.
It returns a bounded baseline, three recovery opportunities, and a short handoff memo. The full
fee is credited if the client starts the $750 pilot within 14 days.

The founding pilot is a fixed-scope, 14-day review priced at **$750**. It uses
client-owned tools and redacted exports where possible. The output is an
evidence-backed map of missed-call and lead-response gaps, plus a small
recovery workflow if the evidence supports one.

Continuation is **$1,500/month only if the measured result is useful**. There
is no guarantee of bookings, savings, or revenue.
